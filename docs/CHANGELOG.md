# MailShield 변경 이력

커밋 단위로 버전을 부여한다. 0.0.x는 개발 중 누적 변경, 0.1.0은 MailShield Tray 1단계 첫 릴리스다.
버전 규칙: `MAJOR.MINOR.PATCH`. 커밋 1건 = PATCH 1 증가, 릴리스 시 MINOR 증가.
