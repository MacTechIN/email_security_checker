# MailShield Tray 배포 안내

이 문서는 두 부분이다. 1장은 **배포하는 사람**(개발자)이 설치기를 만들고 전달하는 절차, 2장은 **받는 사람**에게 그대로 보내도 되는 설치·사용 안내다.

---

## 1. 배포하는 사람용

### 1.1 전달물

| 파일 | 위치 | 크기 | 설명 |
|---|---|---|---|
| `MailShieldTray-Setup-<버전>.exe` | `tray/output/` | 약 50 MB | 사용자별 설치기(관리자 권한 불필요). 이것 하나만 보내면 된다 |
| `docs/08.배포안내.md` 2장 | 이 문서 | – | 받는 사람용 안내. 복사해서 같이 보낸다 |

`tray/dist/MailShieldTray.exe`(exe 단독)를 보내도 실행은 되지만 자동 시작·시작 메뉴·제거 항목이 없으므로 설치기를 권장한다.

### 1.2 설치기 만들기

```powershell
Set-Location "C:\Users\이상진\Documents\email_checker\tray"
.\build\Build-MailShieldTray.ps1
```

테스트 → 아이콘 → exe → 설치기 순으로 만들어 `tray\output\`에 놓는다. 앱이 실행 중이면 `dist\MailShieldTray.exe`가 잠겨 있어 실패하므로 트레이에서 먼저 종료한다. 버전은 `tray/mailshield_tray/__init__.py`의 `VERSION`과 `tray/build/MailShieldTray.iss`의 `MyAppVersion`을 함께 올린다.

### 1.3 전달 방법

- 이메일 첨부는 안 된다. Gmail은 `.exe` 첨부를 차단하고 25 MB 제한도 넘는다.
- **Google Drive / OneDrive 공유 링크**가 가장 간단하다.
- 저장소가 공개이므로 **GitHub Release**에 설치기를 올리면 링크 하나로 배포와 버전 관리가 된다.

  ```powershell
  gh release create v0.1.10 tray\output\MailShieldTray-Setup-0.1.10.exe --title "MailShield Tray 0.1.10" --notes-file docs\CHANGELOG.md
  ```

- 설치기의 SHA-256을 함께 알려 주면 받는 사람이 파일이 바뀌지 않았음을 확인할 수 있다.

  ```powershell
  Get-FileHash tray\output\MailShieldTray-Setup-0.1.10.exe -Algorithm SHA256
  ```

### 1.4 받는 사람의 Gmail 연결 방식 결정

| 방식 | 받는 사람이 할 일 | 배포하는 사람이 할 일 | 권장 |
|---|---|---|---|
| **앱 비밀번호** | Google 계정 2단계 인증 켜기 → 앱 비밀번호 발급 → 설정 창에 입력 | 없음 | **권장.** Google Cloud 프로젝트와 무관하게 동작 |
| Google 로그인(OAuth) | 설정 창에서 "Google 로그인" | Google Cloud Console에서 받는 사람의 Gmail을 **테스트 사용자**에 추가하고, `google_client.json`을 exe에 내장(`tray/mailshield_tray/resources/`)해 빌드 | 현재 OAuth 앱이 테스트 모드라 7일마다 재로그인, 테스트 사용자 100명 제한. 소수 지인 배포에만 |

정식 OAuth 배포(심사 통과)는 `https://mail.google.com/` 범위가 제한 범위라 Google 앱 검증이 필요하다. 상용 단계(개발계획서 2단계)에서 다룬다.

### 1.5 알려진 제약

- **코드 서명이 없다.** 처음 실행 시 Windows SmartScreen이 "PC 보호" 경고를 띄운다. 받는 사람은 "추가 정보 → 실행"을 눌러야 한다. 상용 배포 전에는 코드 서명 인증서가 필요하다.
- 일부 백신이 PyInstaller로 만든 exe를 오탐할 수 있다. 오탐 신고 또는 예외 등록으로 대응한다.
- 실행하면 `%TEMP%\_MEIxxxxxx`에 약 106 MB를 풀고 종료 시 지운다. 강제 종료되면 남으므로 트레이 메뉴의 "종료"로 끝내라고 안내한다. 프로세스는 2개(부트로더 + 앱)가 보인다. 이 두 가지는 onedir 패키징으로 바꾸면 사라진다(`docs/07.경량화계획서.md`, 검증 완료: 프로세스 1개, 기동 2.5초, 임시 폴더 없음).
- 지원 환경은 Windows 10/11 64비트다.

## 2. 받는 사람용 안내

### MailShield Tray가 하는 일

- Gmail 받은편지함과 보낸편지함을 실시간으로 감시해, 주민등록번호·카드번호·계좌번호·전화번호·주소 같은 개인정보가 들어 있는 메일, 실행 파일·매크로 문서·암호 압축 같은 위험한 첨부, 랜섬웨어 협박 문구를 찾아 Windows 알림으로 알려 줍니다.
- 메일 내용은 이 PC 안에서만 검사합니다. 어디로도 보내지 않으며, 탐지된 개인정보 값 자체는 저장하지 않습니다(항목과 건수만 기록).
- 메일을 지우거나 옮기거나 보내는 일은 하지 않습니다. 읽기 전용입니다.

### 준비물

1. Windows 10 또는 11 (64비트)
2. Gmail 계정에 **2단계 인증**이 켜져 있어야 합니다. https://myaccount.google.com/security → "2단계 인증"
3. **앱 비밀번호** 발급: https://myaccount.google.com/apppasswords → 앱 이름에 `MailShield` 입력 → 만들기 → 표시되는 16자리를 복사해 둡니다(공백 포함 상관없음). 이 화면을 닫으면 다시 볼 수 없으니 바로 아래 설치 단계에서 붙여 넣으세요.

### 설치

1. `MailShieldTray-Setup-0.1.10.exe`를 실행합니다.
2. "Windows의 PC 보호" 경고가 뜨면 **추가 정보 → 실행**을 누릅니다. 아직 코드 서명이 없어서 나오는 경고입니다.
3. 설치 마법사에서 "Windows 로그인 시 자동 실행"을 켠 채로 설치합니다. 관리자 권한은 필요 없습니다.
4. 설치가 끝나면 **처음 설정** 창이 자동으로 열립니다. 순서대로 진행합니다.
   - A. 이메일 주소 입력
   - B. "① 2단계 인증 페이지 열기"와 "② 앱 비밀번호 페이지 열기" 버튼을 차례로 눌러 열리는 화면에서 옆의 설명대로 진행하고, 각각 "완료"에 체크
   - C. 복사한 16자리 앱 비밀번호 붙여넣기
   - D. "설정 검사"를 누르면 메일 서버 연결과 폴더 접근을 자동으로 확인합니다
   - E. 검사가 통과하면 "설치 완료(적용)"이 켜집니다. 누르면 설정이 저장되고 자동 실행이 등록되며 감시가 시작됩니다
5. 작업 표시줄 오른쪽 아래 트레이(▲ 숨겨진 아이콘 표시)에 방패 아이콘이 나타나고 초록색이면 감시 중입니다.
6. 나중에 설정이 정상인지 확인하려면 시작 메뉴의 "MailShield Tray 계정 설정"을 열거나, 명령 프롬프트에서 `MailShieldTray.exe --verify --gui`를 실행하면 연결 검사 결과가 창으로 나옵니다.

### 사용

| 동작 | 방법 |
|---|---|
| 상태 확인 | 트레이 아이콘에 마우스를 올리면 "감시 중 (계정: INBOX, 보낸편지함)" 표시 |
| 최근 위험 메일 보기 | 아이콘 더블클릭 또는 우클릭 → "최근 위험 메일 보기" |
| 탐지 근거 확인 | 목록에서 행을 두 번 누르고 "원본에서 근거 확인" |
| 알림이 너무 잦을 때 | 계정 설정 → "'주의' 등급 알림 표시" 끄기(기록은 유지됨) |
| 잠시 멈추기 | 우클릭 → "감시 일시 중지" |
| 종료 | 우클릭 → "종료" (작업 관리자로 강제 종료하지 마세요) |

아이콘 색: 초록 = 감시 중, 빨강 = 위험 메일 감지(1분간), 주황 = 연결 중, 빨간 X = 인증 필요(앱 비밀번호 확인), 회색 = 일시 중지.

### 알림 등급

| 등급 | 뜻 | 예 |
|---|---|---|
| 높음 | 즉시 확인 필요 | 주민등록번호, 카드·계좌번호, 실행 파일·매크로 첨부, 랜섬웨어 문구 |
| 주의 | 개인정보가 들어 있음 | 전화번호, 주소, 실명, 이메일 주소 |
| 정상 | 위험 요소 없음 | 알림 없음 |

받은 메일의 서명에 전화번호나 주소가 있으면 "주의"가 뜰 수 있습니다. 정상입니다.

### 데이터와 개인정보

- 설정·기록·로그: `%LOCALAPPDATA%\MailShield\` (트레이 메뉴 "로그 폴더 열기")
- 앱 비밀번호는 Windows 자격 증명 관리자에만 저장되고 파일로 남지 않습니다.
- 제거: Windows 설정 → 앱 → "MailShield Tray" 제거. 저장된 비밀번호·기록·자동 시작 항목이 함께 지워집니다.

### 문제가 생기면

- 아이콘이 빨간 X: 앱 비밀번호가 틀렸거나 회수된 경우입니다. 새로 발급해 계정 설정에서 다시 입력하세요.
- 알림이 안 옴: Windows 설정 → 시스템 → 알림에서 앱 알림이 켜져 있는지 확인하세요.
- 목록에 있는 메일이 Gmail에 안 보임: 소셜·프로모션 탭에 있을 수 있습니다. 근거 창의 "위치" 줄이 어느 탭인지 알려 줍니다.
- 그 밖의 문제: 로그 폴더의 `tray.log`를 보내 주세요. 로그에는 메일 본문이나 개인정보 값이 들어 있지 않습니다.
