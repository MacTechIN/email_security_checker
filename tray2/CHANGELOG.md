# MailShield 2 변경 이력

v1(`tray/`)과 별개로 동작하는 앱이다. 데이터 폴더·뮤텍스·자동 시작 항목·설치 경로·AppId가 모두 달라 동시 설치·실행이 가능하다.

## 2.0.0 — 2026-09-12 — 기능 개선판

v1.0.x(0.1.12) 기준에서 다음을 추가·변경했다.

### 추가: 링크 검사기 (`links.py`)
- HTML `<a href>`·`<form action>`, 본문 텍스트 URL, PDF 첨부의 `/URI` 주석에서 링크를 뽑는다.
- 높음: 표시 주소와 실제 링크 불일치, `javascript:`/`data:` 스킴, IP 주소 호스트, 퓨니코드·혼합 문자 도메인, 숨긴 링크(display:none, font-size:0), 메일 안 입력 폼.
- 주의: 단축 URL, 리다이렉트 파라미터 안의 다른 사이트, 저평판 최상위 도메인, 발송 대행·클릭 추적 도메인.
- 링크를 열거나 원격 자원을 받지 않는다(추적 픽셀 방지).
- 오탐 대응: 표시 텍스트가 주소를 주장할 때만 불일치로 보고(본문 속 `Ph.D.` 같은 낱말 제외), 알려진 발송 대행 41곳은 주의로만 판정.

### 추가: 발신자 검증 (`sender.py`)
- 수신 서버가 붙인 `Authentication-Results`의 DMARC 실패는 높음, SPF/DKIM 실패는 주의.
- 표시 이름에 실제와 다른 주소가 들어간 위장(높음).
- 회신 주소가 무료 웹메일로 바뀌는 BEC 전형(높음), 다른 도메인이면 주의.
- 국내외 기관·서비스 14종 사칭 판정(국세청·행안부·경찰청·건보·금융위·KISA·네이버·카카오·Google·Microsoft·Apple·택배·쿠팡·은행·텔레그램). 공식 도메인 목록은 KISA 조사(`docs/06`) 반영.
- 제목이 `RE:`/`FW:`인데 원본 대화 참조가 없는 가짜 스레드(주의).

### 추가: 협박 메일 탐지 (`threats.scan_extortion_text`)
- 비트코인(레거시 주소는 Base58 체크섬 검증)·bech32·이더리움 지갑 주소를 찾고, 악성코드·웹캠·기한·유포 위협·결제 요구 지표와 결합될 때만 판정한다.
- 지갑만 있거나 암호화폐 뉴스만 있는 메일은 잡지 않는다.

### 변경: 인증정보 키워드 등급 보정
- 키워드 옆에 실제 값처럼 보이는 문자열이 있을 때만 높음. 단순 언급(`API key를 발급받으세요`)은 주의로 낮춘다.

### 변경: 사건 기록·화면
- `ScanResult.categories`에 탐지 분류(개인정보·링크·발신자·첨부·랜섬웨어·협박)를 남긴다.
- 최근 위험 메일 목록에 "분류" 열, 탐지 상세 창에 "탐지 분류" 줄을 추가했다.

### 검증
- 단위 테스트 117개 통과(v1 82개 + 링크 16 + 발신자 12 + 협박 6, 인증정보 등급 테스트 교체).
- 실계정 회귀: v1에서 오탐이던 LinkedIn 알림은 정상, Kimi 뉴스레터는 주의(발송 대행 링크), 주민번호 테스트 메일은 높음으로 유지.
